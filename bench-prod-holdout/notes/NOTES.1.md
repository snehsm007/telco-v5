This scenario verifies that when a caller asks mid-call in French whether the conversation is being recorded, the agent immediately emits the mandatory recording notice verbatim in French without dropping the French language lock. It relies on the canonical copy `spoken_line("recording_notice", "fr-CA")` (`"Cet appel peut être enregistré à des fins de qualité et de formation."`) and the explicit trigger rule in `cxas_app/agents/router/instruction.txt` (step "Answer Recording Question"). Current agent expected outcome: **Pass** — the router prompt directly instructs emitting the exact verbatim copy whenever the recording question is posed.

### prod__br004_language_lock_switch_fr (BR-TV-004 / BR-TV-020)

### prod__br005_cross_module_warranty_cancel_en (BR-TV-005)
This scenario validates handling two disparate customer intents across distinct specialist modules in a single call: a hardware warranty replacement claim followed by a service cancellation request. It relies on the `manage_warranty_claim` tool in the `sales_equipment` agent and the `cancel_or_port_out_service` tool in the `account` agent, verified against account profile fixtures. Current agent expected outcome: **Likely gap** — while the router can dispatch to specialist agents individually, sequential cross-agent handoffs between two specialist sub-agents (`sales_equipment` transitioning to `account`) frequently fail to re-enter the router or maintain state context across module boundaries.

### prod__br006_retry_strikes_no_input_en (BR-TV-006)
This scenario evaluates no-input retry strike handling by having the simulator submit three consecutive silent turns consisting solely of `...` when prompted for account details. It relies on the PRD error threshold (`local_noinput_counter >= 3`) triggering live agent escalation with `spoken_line("live_agent_handoff", "en-US")` (`"I'll connect you to a representative who can help.
